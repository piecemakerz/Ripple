## AI와 제품 범위

현재 앱에는 모델 호출·문서 추출·에이전트 실행이 없다. 샘플 문서와 관계는 고정 입력이지만 영향 탐색과 저장은 실제 DB 작업이다. 화면도 합성 샘플과 AI 추출 미사용을 명시한다.

앱 내부 LLM, 멀티에이전트, MCP, 벡터 검색은 확인한 필수 항목에 없으며, 메인은 앱과 사람의 연결 정보 활용도 대상으로 한다. 따라서 이 기능들의 부재만으로 부적격이라고 판정하지 않는다. 이는 [메인 안내](https://relate.devpost.com/)를 대조한 해석이다. [주최 측 발표 글](https://neo4j.com/blog/graph-database/announcing-the-relate-by-neo4j-hackathon-2026-build-ai-agents-on-an-embedded-graph-database/)은 AI·에이전트 활용을 강조하므로 향후 경쟁력 개선 방향으로는 고려할 만하다.

제품의 확장성은 아직 제한적이다. 임의 문서 입력, 관계 후보 확인·편집, 일반 변경 생성 UI가 없고 한 시나리오를 보여준다. 현재 작품을 **변경 영향 검토 MVP**로 설명하면 구현과 일치한다. **임의 문서를 자동 분석하는 AI 제품**이라고 제출하면 현재 동작으로 뒷받침할 수 없다.

개발 AI와 제품 AI도 구분해야 한다. 이번 코드·테스트·문서 작성에는 Codex가 사용되었다. `gpt-6-astra`는 앞으로 사용할 모델 설정이며 실제 Astra 추론 실행을 확인한 기록은 없다. 제출 설명에서 설정을 실제 사용 실적으로 바꾸어 쓰지 않는다.

## 안내의 차이와 사용자 확인 항목

- 메인·발표 글은 기존 프로젝트 확장을 허용하지만 Rules §3은 신규 프로젝트만 명시한다. Ripple은 이번에 신규 구현했으므로 현재 증거상 직접 충돌하지 않는다.
- 메인은 가중 배점, Rules는 동일 가중치, 발표 글은 AI 활용까지 별도로 언급한다. 주최 측에 최종 기준을 확인하는 것이 좋다. 이번 감사에서 메시지를 보내지는 않았다.
- 연령은 만 18세 이상 또는 현지 성년 기준 중 더 높은 기준이다. 거주 제한, Neo4j/정부기관 관련자·가족, 운영 관계자 제외, 1~4명·한 팀 조건을 본인이 확인해야 한다. 언어는 영문 Rules 우선이라는 규정이며 영문 제출 의무를 확인한 것은 아니다. [Rules §2–3, §13](https://relate.devpost.com/rules)
- 자체 오픈소스 라이선스는 Rules에서 권장한다. LICENSE 부재만으로 탈락이라고 단정하지 않는다. 제삼자 라이선스 준수와 재사용 공개는 별도 의무다. [Rules §3, §8](https://relate.devpost.com/rules)

## 보완 우선순위와 완료 기준

### 먼저: 제출 가능 상태

1. **공개 저장소 연결:** Ripple 파일만 검토해 커밋하고 공개 URL·토픽·유지 기간을 확인한다. 아직 업로드하지 않았다.
2. **심사용 영구 DB:** 개인 DB와 별개로 합성 샘플을 생성·체크포인트·정상 종료하고 `submission/sample-store/` 같은 경로에 보관한다. 복사본을 별도 프로세스로 다시 열어 검증하고 README에 위치/조회 방법을 명시한다. 활성 DB를 통째로 Git에 추가하지 않는다.
3. **제출 설명·데모:** 1~2분 영상에서 변경, 직접/간접 영향, T3 제외, 원문, 검토, 재시작을 보여준다. 로그인 없이 재생되는 URL을 확인한다. Devpost 작성/제출 여부는 별도다.
4. **도구·AI 사용 공개:** 개발 과정에서 AI가 수행한 작업, 사람이 확인한 범위, 실제 사용 모델을 구분하고 샘플이 합성 자료임을 명시한다.
5. **배포 고지 확인:** 현재 직접 의존성은 Relate/TypeScript Apache-2.0, React/Express/Vite/Zod 등 MIT, Lucide ISC, 두 폰트 OFL-1.1로 표시된다. 실제 라이선스 파일·전이 의존성·배포 형태까지 확인해 필요한 고지를 포함한다. 이 감사는 전체 라이선스 적합성 법률 검토가 아니다.

### 다음: 작품의 설득력

6. **영문 README와 설명:** Mode / 선택 이유 / 그래프 모델 / 첫 결과 / 제출 DB 경로를 명시하고, 개발 환경 설정 설명보다 심사자의 실행 순서를 먼저 제시한다.
7. **M2 최소 범위:** 문서 붙여넣기 → 원문 버전 저장 → 사람이 확인한 관계 → 변경 영향까지 확장한다. AI 추출은 예산·모델 결정 후 후보 생성으로 붙인다.
8. **실제 피드백:** 새로운 문서 사례와 작은 사용자 검증을 추가한다. 사실로 측정한 결과만 제출 설명에 사용한다.

공개 저장소 생성, 라이선스 선택, 영상 업로드, Devpost 등록·제출, 참가 조건 동의는 이번 검증에서 수행하지 않았다.

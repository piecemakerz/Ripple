# Ripple 첫 화면·검토 화면 시안 비교

2026-11-15 · Product Design의 ideate 절차와 내장 ImageGen을 사용했다. 각 이미지의 위쪽은 첫 화면, 아래쪽은 검토 화면이다. 아래 비교는 선택 전 정적 제안의 기록이다. 번호는 대화에 실제 표시된 이미지 순서다. 이후 해커톤 기준의 선택을 위임받아 **3안을 구현했다**. 구현 결과는 다음 절에 기록한다.

## 해커톤 기준 선택과 구현 결과

후속 업데이트: 구현 후 사용자가 시각적 완성도에 불만을 표현했다. D14는 연결 중심 흐름을 유지하면서 밝은 헤더, 절제된 색 면적, 위로 옮긴 시작 버튼과 로컬 한글 글꼴로 정돈했다. 아래는 최초 선택/구현 기록이며, 현재 표현과 사용자 수용의 한계는 [후속 시각 기록](VISUAL_REFINEMENT.md)을 따른다.

**3 · 연결을 보는 지도 / Ripple Map**을 선택했다. [공식 안내](https://relate.devpost.com/)와 [공식 규정](https://relate.devpost.com/rules)은 수치 배점이 상충하지만, 연결 맥락의 실제 활용·작동하는 제품·명료한 설명을 공통으로 요구한다. 변경→결정→작업→원문 근거를 화면에서 직접 따라갈 수 있는 3안이 이 시연 목적에 가장 적합하다는 설계 판단이다. D12의 첫 사용 중심 1안 추천은 당시 판단으로 보존하며, 새 기준의 선택은 D13에 별도로 기록했다. 수상 가능성이나 사용성 향상의 측정 결과는 아니다.

선택된 이미지의 forest/teal 헤더, 살구색 변경 요약, 지도 중심 첫 화면과 지도·근거/판단 분리 구성을 실제 native 데이터로 구현했다. 좁은 화면에서는 시작 버튼을 지도 앞으로 옮기고 선택한 근거로 초점을 이동한다. 원문·한국어 읽기 보조·명시적 저장·실패 재시도·판단 이력을 보존했다. 실제 데이터 자동 배치와 저장 상태에 따른 차이는 [시각 검증](../design-qa.md)에 설명한다.

실행 결과: verify 72/72, 데스크톱/390px의 실제 적용·저장·실패·재시도·복원을 확인했다. [첫 화면](evidence/ripple-map-entry-desktop.jpg), [검토 화면](evidence/ripple-map-review-desktop-full.jpg), [모바일](evidence/ripple-map-entry-mobile.jpg), [개발 검증 기록](QA.md). 새 사용자 관찰과 심사 결과는 미확인이다. 로컬 미리보기는 `http://127.0.0.1:4353/`; 공개 배포는 하지 않았다.

## 선택 전 비교

| 시안                              | 첫 화면                                | 검토 화면                              | 적합한 목표                        | 대가                                                        |
| --------------------------------- | -------------------------------------- | -------------------------------------- | ---------------------------------- | ----------------------------------------------------------- |
| 1 · 따뜻한 시작 / Warm Focus      | 따뜻한 살구색 변경 요약과 큰 체험 버튼 | 한 항목의 이유·원문과 민트색 판단 영역 | 친근한 첫인상과 명확한 첫 행동     | 한 번에 여러 항목을 비교하기는 어렵다                       |
| 2 · 정돈된 작업대 / Clear Desk    | 변경 전후 비교와 결정→작업 목록        | 항목 목록·원문·판단을 나란히 배치      | 반복 검토와 빠른 항목 전환         | 처음 보는 사용자에게 정보량이 많을 수 있다                  |
| 3 · 연결을 보는 지도 / Ripple Map | 전제→결정→작업의 두 경로를 크게 표시   | 선택한 경로 아래에 원문 근거 연결      | 직접·간접 영향을 이해하고 설명하기 | 관계가 늘어나거나 화면이 좁아지면 별도 탐색 설계가 필요하다 |

당시 친근함·신규 사용자 진입 목표에는 **1안을 우선 추천**했다. 세 시안의 사용성 순위가 측정되었다는 뜻은 아니다. 이후 해커톤 기준의 위임 선택과 3안 구현은 위 절을 따른다.

## 사용한 근거와 보존한 조건

- 실제 첫 화면: [한국어 첫 진입 캡처](evidence/first-look-ko-desktop.jpg).
- 실제 검토 화면: [단일 항목 검토 캡처](evidence/first-look-review-desktop.jpg).
- 두 이미지를 직접 확인하고 모든 이미지 생성에 첨부했다. 저장된 Product Design 사용자 문맥 파일은 없었다.
- 세 결과에서 한국어 읽기 보조, 영어 원문, D1/D2/T1/T2의 네 영향, 유지·수정·보류와 이유 입력, 명시적 저장 행동을 확인했다. 그래프의 화살표는 영향 전파 순서이며 저장된 `DEPENDS_ON` 방향을 바꾸는 제안이 아니다.

## 구현 전에 확인할 항목

- 1안의 생성된 유지 설명은 “영향이 없으므로”라고 쓰여 있다. 실제 의미는 변경 후에도 기존 판단이 유효하다는 것이므로 문구를 교정해야 한다. 수정 선택 역시 실제 구현을 완료하는 버튼이 아니다.
- 이미지의 영어 원문은 시각 참고다. 구현에서는 보존된 소스·인용·범위와 기존 API를 그대로 사용한다.
- 현재 이미지는 데스크톱 표현을 비교한다. 모바일 재배치, 대비 수치, 키보드·스크린리더 동작, 오류·빈 결과·조회 한도 상태는 검증하지 않았다.
- 준비된 예제 그림은 새 권위 데이터가 아니다. 실제 영향은 기존 native Relate 결과만 사용한다. 원문 열기와 저장 등의 동작은 정적 이미지로 검증할 수 없다.
